# Dijital-Miras-Sifir-Bilgi-Dijital-Miras-Kasasi
Dijital Miras, bireylerin finansal hesaplar, kripto cüzdanlar, sosyal medya ve bulut depolama gibi dijital varlıklarının; vefat veya iş göremezlik durumunda yasal mirasçılarına güvenli biçimde aktarılmasını sağlayan sıfır bilgi  mimarili yerli bir web platformudur.
